# G-DRAGON — POWER Interactive Visual Experience

Open `index.html` in a modern browser. No build step is required.

## Interactions
- Drag the square lens with mouse or touch.
- As the lens moves across the screen, it cycles through five visual treatments: Monochrome, Red Shift, Negative, X-Ray, and Duotone.
- The underlying portrait shifts subtly in crop, hue, and parallax to make the full-screen backdrop feel alive.
- Use arrow keys on the circular handle to move the lens, Shift + arrows for larger moves, Page Up / Page Down to switch treatments, and Home or RESET VIEW to return to the start.
- Responsive desktop and mobile layout, with reduced-motion preference support.

Replace `assets/poster-background.png` with your own image (keep the same filename) to change the artwork.
